# Panduan proyek Izzan Digital Printing

Proyek ini mendukung perancangan aplikasi dan penulisan skripsi tentang analisis pola pemesanan layanan percetakan dengan K-Means.

- Untuk perencanaan aplikasi, implementasi, atau penulisan skripsi, gunakan `KONTEKS_PROYEK.md` sebagai acuan kebutuhan, keputusan, usulan, dan pertanyaan yang masih terbuka.
- Berkomunikasi dalam bahasa Indonesia. Pengguna terbiasa dengan Laravel, memiliki kemampuan coding dasar, dan belum terbiasa dengan Python. Jelaskan bagian penting agar pengguna dapat memahami aplikasi dan mempertanggungjawabkan algoritma saat sidang.
- Perangkat pengguna adalah MacBook M1. Editor adalah VS Code. Pengguna menggunakan XAMPP dan phpMyAdmin untuk pengelolaan database lokal. Jangan menganggap versi PHP, server database, atau runtime lain sudah diverifikasi.
- Pengguna telah memilih **PHP dengan framework Laravel untuk seluruh backend, termasuk K-Means**. Jangan menambahkan modul atau layanan Python kecuali pengguna kemudian meminta perubahan teknologi. Pilihan pustaka PHP untuk analisis belum ditetapkan.
- Utamakan analisis pola pemesanan yang membantu pengelola memperhatikan kebutuhan bahan dan masalah kekurangan stok. Fitur pemesanan dan pembayaran mendukung fokus tersebut.
- Pisahkan keputusan pengguna, usulan teknis, hasil observasi, dan hal yang masih perlu diselaraskan dengan dosen. Jangan memperlakukan seluruh ide diskusi sebagai kebutuhan final.
- Data dummy digunakan untuk pengembangan dan simulasi. Jangan menyebutnya data nyata toko atau hasil penelitian lapangan.
- Pembahasan K-Means harus membedakan rekap transaksi, pengelompokan, prediksi, dan penjelasan sebab. Jangan mengklaim clustering otomatis meramalkan stok atau menjelaskan alasan pelanggan membeli.
- Dalam chat diskusi, jangan mulai membangun aplikasi atau mengubah skripsi tanpa permintaan pengguna. Jika chat baru meminta implementasi, lanjutkan pekerjaan yang diminta dengan mengacu pada catatan proyek.
- Saat ada keputusan atau perubahan penting, perbarui bagian terkait dalam `KONTEKS_PROYEK.md`; jaga catatan tetap ringkas dan sesuai kondisi terbaru.
